Python Utility Module

Description

This project creates a reusable Python utility module containing commonly used functions for validation, formatting, calculations, and file handling.

Objective

To learn modular programming and code reusability in Python.

Files

- "utility.py" – Contains reusable utility functions and an example program.
- "main.py" – Demonstrates how to import and use the utility module.
- "output.txt" – Created automatically when the program runs.

Functions

1. validate_email(email) – Checks whether an email address contains valid basic email characters.
2. format_name(name) – Removes extra spaces and capitalizes the name.
3. calculate_percentage(part, total) – Calculates the percentage of a value.
4. calculate_average(numbers) – Calculates the average of numbers in a list.
5. write_to_file(filename, content) – Writes content into a text file.
6. read_from_file(filename) – Reads content from a text file and handles missing files.

How to Run

1. Save the files as "utility.py" and "main.py" in the same folder.
2. Open the terminal in that folder.
3. Run the following command:

python main.py

Concepts Used

- Python modules and functions
- Code reusability
- Input and output
- File handling
- Exception handling
- Conditional statements

Conclusion

The Python Utility Module demonstrates how commonly used functions can be organized into a reusable module and imported into other Python programs.
